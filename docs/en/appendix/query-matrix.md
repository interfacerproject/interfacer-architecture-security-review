# Zenflows matrix query

**62 root fields** imported from source to [manifest](repository-map.md) commit. All lines are about Zenflows GraphQL `/api` and the same schema on `/play`. camelCase names derived from Absinthe symbols.

**Auth:** S = MW.Sign; A = MW.Admin; G = no credentials required (meta only_guest does not prohibit authenticated users). With `GQL_AUTH_CALLS=false`, S and A are not enforced: this setting is not assumed in production. The controls column distinguishes authentication from authorization. FK/changeset can reject data but do not prove ownership. Complete static inventory of imported fields, not exhaustive dynamic testing.

## Coverage and limits

The gate is root-level: a guest query can resolve nested relationships without passing through the gate of a signed root query of the same type. Image, agent, trace, and DPP trace resolvers must be protected by data, not just by root field name.
