# Mutation matrix Zenflows

**81 root fields** imported from source to [manifest](repository-map.md) commit. All lines are about Zenflows GraphQL `/api` and the same schema on `/play`. camelCase names derived from Absinthe symbols.

**Auth:** S = MW.Sign; A = MW.Admin; G = no credentials required (meta only_guest does not prohibit authenticated users). With `GQL_AUTH_CALLS=false`, S and A are not enforced: this setting is not assumed in production. The controls column distinguishes authentication from authorization. FK/changeset can reject data but do not prove ownership. Complete static inventory of imported fields, not exhaustive dynamic testing.

## Coverage and limits

`createEconomicResource` or `deleteEconomicEvent` do not exist in the imported root: resources are created via events; instead, there is an internal primitive `multi_delete` event. Commitment, Fulfillment, Claim, Settlement and other commented imports are not active APIs in the analyzed schema. The raw and import functions require separate inventory; the coverage check does not prove the correctness of the permissions.
